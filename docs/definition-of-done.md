# Definition of Done

- [ ] Demande et critères d'acceptation tracés sans donnée sensible
- [ ] Plan approuvé pour tout changement transversal ou risqué
- [ ] Branche dédiée et contexte ciblé utilisés
- [ ] Architecture et conventions respectées
- [ ] Validation, permissions, Policies et BOLA/IDOR traités
- [ ] Migrations PostgreSQL sûres et seeders idempotents
- [ ] Tests comportementaux ciblés réussis
- [ ] Suite pertinente PostgreSQL/Redis réussie
- [ ] Couverture de 85 % respectée lorsque mesurée
- [ ] Pint et PHPStan réussis
- [ ] Composer validate/audit et scan de secrets réussis
- [ ] OpenAPI régénéré et synchronisé si contrat modifié
- [ ] Documentation humaine mise à jour
- [ ] Rules, Skills et liens vérifiés
- [ ] Trace append-only complétée avec commandes/résultats réels
- [ ] Diff relu et fichiers inattendus exclus
- [ ] `scripts/ai/validate.sh` réussi
- [ ] Approbations Git enregistrées
- [ ] Commit/push/PR effectués uniquement via scripts sûrs
- [ ] Aucun push protégé, force push ou merge automatique

Une commande bloquée ou non exécutée est explicitement signalée; elle n'est jamais marquée réussie.
