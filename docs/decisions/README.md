# Registre des décisions

Les décisions d'architecture documentent le contexte, le choix, ses conséquences et son statut. Elles ne remplacent ni le code ni les tests.

| ID | Décision | Statut |
|---|---|---|
| [0001](0001-modular-monolith.md) | Monolithe modulaire Laravel-native | Acceptée |

Une nouvelle décision reçoit le prochain numéro, reste courte et référence les contraintes réelles. Une décision remplacée n'est pas supprimée : elle est marquée « Remplacée par ».
